# NETWORKWALKS CYBERSECURITY INTERNSHIP – WEEK 3

## Password Cracking and Security Assessment

**Batch:** B082  
**Focus:** Password Security and Hash Cracking

## Project Overview

This repository documents my Week 3 practical activities as part of the NetworkWalks Cybersecurity Internship.

The exercises focused on understanding password security, PDF hash extraction, password recovery techniques, and the use of command-line and online security tools.

## Projects Completed

### PM1 – John the Ripper and Johnny GUI

Practical password recovery using Kali Linux, pdf2john, John the Ripper, and Johnny GUI.

Activities included:
- Extracting password hashes from encrypted PDF files.
- Saving and processing hash files.
- Performing password recovery using John the Ripper.
- Verifying recovered passwords.
- Using Johnny GUI to load hashes and observe cracking results.

[View PM1 Project](./PM1-JOHN-THE-RIPPER/)

### PM2 – NetworkWalks Password Security Tools

Practical exercises using:
- NetworkWalks Hash Calculator.
- NetworkWalks Password Cracker.

Activities included:
- Exploring hash calculation and identification.
- Processing three encrypted PDF practice files.
- Recovering passwords.
- Documenting results through screenshots.

[View PM2 Project](./PM2-NETWORKWALKS-TOOLS/)
