# PM2 – NetworkWalks Password Security Tools

## 1. Project Overview
This project explores password security and recovery using the NetworkWalks online Hash Calculator and Password Cracker tools.

## 2. Objectives
- Understand password hashes and hash identification.
- Practise using online hash calculation tools.
- Explore password recovery using a password-cracking tool.
- Understand the security risks associated with weak passwords.

## 3. Tools Used
- NetworkWalks Hash Calculator
- NetworkWalks Password Cracker
- Web browser
- Three encrypted PDF practice files

## 4. Practical Activities
1. Accessed the NetworkWalks Hash Calculator.
2. Used the calculator to generate and examine hash values.
3. Accessed the NetworkWalks Password Cracker.
4. Submitted the practice files for password recovery.
5. Observed the password-cracking results for the three PDF files.
6. Captured screenshots documenting the practical activities.

## 5. Results
The three practice PDF files were successfully processed, and their passwords were recovered using the NetworkWalks tools.

## 6. Security Lessons
- Hashing transforms data into fixed-length values.
- Password hashes should not be treated as encrypted passwords.
- Weak passwords can be vulnerable to guessing and offline attacks.
- Strong, unique passwords help protect sensitive documents.
- Password recovery tools should only be used on files you own or have permission to test.

## 7. Conclusion
This exercise provided practical exposure to online hash calculation and password recovery tools. It improved my understanding of password security, hash values, and the importance of strong authentication practices.

**Note:** Screenshots are included as supporting evidence. Sensitive passwords and hash values have been excluded from the public documentation.
